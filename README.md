# Patient Management System

A backend-based Patient Management System developed using Spring Boot, SQL, JPA/Hibernate, and REST APIs. The project provides APIs for managing patient information and demonstrates database integration and API testing using Postman.

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- SQL / MySQL
- REST API
- Postman
- Maven
- IntelliJ IDEA

## 📌 Features

- Add a new patient
- Get patient details
- Get all patients
- Update patient information
- Delete patient
- Store and retrieve patient data from SQL database
- RESTful API implementation
- API testing using Postman
- Database interaction using JPA/Hibernate
